ЧТО ЗА ПРИЛОЖЕНИЕ
Семейное PWA-приложение. Родитель создаёт задания, ребёнок отмечает «Выполнено», родитель
подтверждает, ребёнку начисляются баллы, баллы обмениваются на награды. Один код на всех телефонах.
Оба родителя равноправны (нет «главного админа»). Пользователь не программист: объяснять просто.
Язык интерфейса: русский.

СТЕК (решено, не менять без причины)
React 18 + TypeScript + Vite, Tailwind CSS 3, Framer Motion, react-router-dom 6, lucide-react,
vite-plugin-pwa, Supabase (auth, Postgres, RLS, realtime, storage). Хостинг: Netlify из GitHub (netlify.toml в проекте, бесплатно).

РЕШЕНИЯ
- Вход ребёнка: вариант А, своя почта и пароль, присоединение по коду приглашения.
  (Вариант Б, вход по PIN, возможен позже.)
- Баллы: только журнал points_transactions, баланс = сумма. Операции через SQL-функции (атомарно,
  идемпотентно). Ребёнок не пишет в баллы/награды/роли напрямую.
- Уведомления MVP: внутри приложения через realtime. Push при закрытом приложении: позже.
- Offline: не offline-first. Баннер «нет связи», блокировка кнопок, переподключение и перезагрузка данных.
- Дизайн: фон paper #F5F6FB, основной brand #4F46E5, баллы star #F5A524, подтверждено ok #1FA971,
  на проверке review #8B5CF6, ошибка warn #E5484D. Шрифты: Unbounded (заголовки/числа), Onest (текст).

БАЗА / RLS / АВТОРИЗАЦИЯ
SQL написан (см. выше). Ключевые решения: все изменения баллов/заявок/ролей только через SQL-функции
(create_family, create_invite, join_family, remove_child, submit_task, approve_submission, reject_submission,
request_reward, approve_redemption, reject_redemption); у клиента нет прав писать в баллы/роли. Родители равны.
Задания: статусы todo/submitted/approved/rejected, «просрочено» считается на клиенте (due_at < now). Повтор: при
подтверждении создаётся следующее задание (next_due). Баланс = view child_balances (сумма journal).
Коды приглашения: 10 символов, одноразовые, 7 дней. Один пользователь = одна семья.
Уведомления создаются триггерами/функциями в таблицу notifications (клиент их только читает). Таблицы по плану: profiles, families, family_members (только parent|child),
family_invites, tasks, task_submissions, points_transactions, rewards, reward_redemptions, notifications.
